# Predict Me Some Dinner!

A place for me to keep track of proposition bets I've go going with various folks.

## Basic Structure

All bets follow a standard structure, which I've modeled as a template `Issue`. When there's a reason to thematically group a set of bets, I put them into a `Project`.

## The Stakes

All bets are for dinner at a place of the winner's choosing. We follow a Seinfeldian model, here; Soup counts and Kenny Bania was out of line!
